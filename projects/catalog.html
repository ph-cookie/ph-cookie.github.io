MoneyPrinterTurbo — 台本・音声・素材を組み合わせるショート動画制作ツール

テーマやキーワードから台本、ナレーション、映像素材、字幕、BGMを組み合わせ、短い動画の制作を自動化するツール。

MoneyPrinterTurboは、テーマやキーワードをもとにショート動画を制作するツール。AIによる台本作成、ナレーション生成、素材の検索・取得、字幕付与、BGMの追加、動画の合成をまとめて行える。自分で用意した台本・画像・動画・音声を使い、各工程を調整することもできる。

ブラウザのWebUI、API、CLIから操作でき、複数動画の一括生成や自動化フローへの組み込みに対応する。Pexels・Pixabayなどのストック素材に加え、対応サービスで生成した画像や動画も利用できる。縦長・横長・正方形の動画を出力し、字幕のフォント・位置・色や、素材の長さ・画面への収め方などを設定できる。

LLM、音声合成、素材サービスは用途に応じて選び、外部サービスによってAPIキーや利用料金が必要になる。GPUは必須ではないが、ローカルWhisperなど負荷の高い処理では性能が影響する。本体はMITライセンスで、同梱BGMや使用する素材の権利条件は個別に確認する必要がある。

Graphify — コードや文書の関係を検索できる知識グラフ作成ツール

コードや文書の構造と関係を知識グラフにまとめ、依存関係の検索・経路追跡・可視化に使えるツール。

Graphifyは、ソースコードや文書、PDF、画像などを知識グラフにまとめ、プロジェクト内の関係を調べるツール。コードから関数・クラス・呼び出し・インポートなどを抽出し、要素どうしのつながりや機能ごとのまとまりを確認できる。初めて触れるコードの構造把握や、変更前に関連箇所をたどる用途に使える。

生成したグラフは、ブラウザで操作できるHTML、概要をまとめたMarkdown、グラフ全体のJSONとして保存される。CLIから質問に関係する部分グラフを検索したり、2つの要素を結ぶ経路をたどったりできる。Claude Code・Codex・CursorなどのAIコーディングツールと連携し、コードを読み直す前にグラフを参照させる使い方にも対応する。

コードの構造抽出はtree-sitterでローカル実行され、コードのみならAPIキーなしで利用できる。文書や画像などの意味解析には、AIアシスタントまたは設定したLLMバックエンドを使い、外部APIを選ぶと対象データが送信される。コードだけを対象にする場合は --code-only で文書などを除外できる。資料の種類や連携方法によって追加パッケージや設定が必要で、抽出した関係と推定した関係は区別して表示される。

Claude Security — コードの脆弱性調査と修正案を作るClaude Codeプラグイン

リポジトリ全体やコード差分を調べ、脆弱性の検証結果を報告書にまとめ、修正用のパッチ案も作成するClaude Codeプラグイン。

Claude Securityは、Anthropicの公式プラグイン集に収録された、Claude Code向けのセキュリティ調査プラグイン。複数のエージェントがコードの構造把握、脅威モデルの作成、脆弱性の探索を分担し、候補を別のエージェントが検証してから報告書にまとめる。リポジトリ全体、一部のディレクトリ、ブランチやプルリクエストの差分、特定コミットを調査できる。

調査結果はMarkdown・JSONL・SARIF形式で保存される。確認済みの指摘から修正パッチ案を作る機能もあり、作業ツリーとは別のコピーで修正とレビューを行う。パッチの適用・コミット・pushは自動では実行せず、利用者が内容を確認して適用する。

調査と修正案の作成はClaude Codeのセッション権限で動き、プラグイン独自の隔離機能はない。自分が管理するコードでの利用に向いており、信頼できないリポジトリを扱う場合はセッション全体の隔離が推奨される。調査結果は実行ごとに変わる可能性があり、静的解析・依存関係の検査・コードレビューを補う用途で使う。

▼利用条件

AIツール【必須】Claude Code（Claude Securityプラグイン導入済み）
実行環境【必須】Python 3.9以降（PATHに登録）
必要ソフト（差分の調査・修正パッチ案の作成）【必須】Gitチェックアウト（リポジトリ全体の調査だけなら不要）

▼仕様・出力

形式・出力調査結果：Markdown・JSONL・SARIF 2.1.0。修正案：パッチファイル。

▼利用方法

参照方法Claude Codeで /plugin install claude-security@claude-plugins-official と /reload-plugins を実行し、/claude-security から利用する。

▼ライセンス

ライセンスAnthropic独自ライセンス。契約条件に従い、Claude CodeなどAnthropic製品・サービスでの内部利用に限定。契約で明示的に許可される場合を除き、第三者への再配布や非Anthropic製品での利用は禁止。

imozuru（いもづる）— 原文と引用をたどるAIリサーチスキル

未知の分野の用語・人物・情報源を探し、引用やリンクをたどって原文を収集し、調査した主張と根拠の箇所を対応づけるClaude Code向けスキル。

imozuru（いもづる）は、Claude Codeで未知の分野を調査し、根拠となる原文を集めるリサーチスキル。最初に調査したい問いを整理し、専門用語、中心となる人物、情報が集まる場所を探す。そこから論文の参考文献・被引用文献、記事のリンク、著者の発信をたどる。論文だけでなく、ブログやYouTubeなどの個人の発信も対象にする。

ImageOptim-CLIは、macOSの画像最適化アプリをコマンドラインから操作し、画像の一括圧縮を自動化するツール。ImageOptim、ImageAlpha、JPEGminiと連携し、Webサイトの画像素材の軽量化や、公開前のビルド処理への組み込みに使える。本体はRust製で、npmからMac向けのバイナリを配布している。

主述関係や不自然な比喩、過剰な装飾を見直し、元の意味や文体を尊重して日本語を推敲するエージェントスキル。

yomiyasu（よみやす）は、AIが生成した日本語を推敲するエージェントスキル。Claude CodeやCodex、Cursorなどに導入し、技術記事、仕様書、レポート、エッセイなどを整える。単語の置き換えにとどまらず、主語と述語、修飾語、条件や否定の関係まで確認する。

元の主張・文体・言い切りの強さを尊重し、根拠のない情報を加えずに、不自然な比喩や不要な強調、文のつながりを見直す。技術記事・業務文書・エッセイに応じた指針があり、文章を渡して用途を指定できる。表現やMarkdownの書式を検査するyomiyasu_lint.pyと、推敲前後の語句・文末・構造の変化を確認するyomiyasu_diff.pyも付属する。

検査ツールの指摘は見直し候補であり、文章の自然さや意味の保持を保証するものではない。AI製か人間製かを判定する機能もない。類似する校正スキルとの併用では指示が競合する場合がある。READMEで紹介された外部試験では、生成前にスキルを読ませる使い方で、情報の加筆が減った一方、文章が短くなり、読みやすさの評価も下がった。少数の文章をAIが採点した試験であり、すべての用途で改善するとは限らない。コードとドキュメントはMITライセンスで公開。

Insomnia — Macの長時間処理・省電力管理ツール

AIエージェントの長時間実行に向けて、不要なアプリの一時停止や省電力制御を行い、Macのバックグラウンド処理環境を整えるツール。

Insomniaは、AIエージェントなどの長時間処理に向けて、終了時刻を決めたスリープ防止と省電力制御を行うmacOSのメニューバーアプリ。蓋を閉じた状態での処理継続にも対応。

セッション中にMacBookの蓋を閉じると、設定に応じてSlack・Discordなどのアプリを一時停止し、画面・キーボードのバックライト消灯、音声ミュート、低電力モードへの切り替えを行う。ほかのDockアプリを広く停止する設定は初期状態では無効で、設定済みのAIエージェントや保護対象のアプリは除外される。常時アプリを停止する最適化機能ではない。

バッテリー残量や本体の温度状態に応じて、低電力モードへの移行やセッション終了を制御する。蓋を開くと一時停止したアプリや設定の復元を試み、異常終了後は保存された終了時刻を過ぎると復旧エージェントが回復を試みる。

配布アプリはAppleの公証未取得で、初回起動はmacOSにブロックされる。Swift製でMITライセンス。蓋を閉じてもMacが動作するため、排熱できる安定した場所で使い、バッグに入れたまま使用しない。

▼利用条件

OS・CPU【必須】macOS 26以降／Apple Silicon（配布版はarm64専用）
導入条件【必須】インストール時に管理者権限が必要。
実行環境（ソースビルド）【必須】ソースビルドはXcode・Swift 6.2以降

PluginKits — macOS拡張機能管理ツール

macOSにインストールされた拡張機能を一覧表示・管理し、Quick Lookの競合や動作不良の解消を支援するツール。

PluginKitsは、macOSに登録された.appex形式の拡張機能を一覧表示・管理するツール。Quick Lookの競合を検出し、同じファイル形式に使う拡張機能を選択できる。

拡張機能の識別子・保存場所を確認し、個別に有効化・無効化や登録・解除を行えるため、プレビュー不良の原因調査や不要な拡張機能の整理に使える。

Swift製で、公式説明ではシステム権限を要求せず、アプリの外向きネットワーク通信を無効化している。公式READMEはオープンソースと説明しているが、具体的なライセンス名は未確認。

▼利用条件

OS【必須】macOS 13 Ventura以降
CPU【必須】Apple Silicon・Intel
配布版の条件macOS 14未満はGitHub ReleasesのVentura用配布版を選択

mcopt — Apple Silicon向けMinecraft最適化MOD

Apple Silicon搭載Macで、Minecraftの描画処理をMetalに置き換え、動作の高速化を目指す最適化MOD。

mcoptは、Apple Silicon搭載Mac向けのMinecraft Java Edition最適化MOD。OpenGLベースのワールド描画を独自のMetalレンダラーに置き換え、より滑らかな動作を目指す。

公式READMEの測定では、Mac mini M4（10コアGPU・16 GB）、1920×1080、描画距離16、VSync無効の同一ワールドで、旋回時の通常版156 FPSに対しmcopt 0.3.0-alpha.1は1209〜1211 FPSだったが、すべての環境で同等の向上を保証する数値ではない。

最新リリースは0.3.0-alpha.2のAlpha版で、バグに備えて導入前のワールドのバックアップが推奨される。Sodiumは不要かつ併用不可で、Sodium依存のMODやOpenGLを直接呼ぶMODにも互換性の制約がある。Apache License 2.0で公開。

▼利用条件

OS・CPU【必須】macOS 26以降／Apple Silicon
実行環境【必須】Minecraft 26.3／Java 25／Fabric Loader 0.19.5以降
描画API【必須】Metal 3

REA — AI連携リバースエンジニアリングツール

AIエージェントと連携し、アプリや実行ファイルの内部構造・動作を解析できるリバースエンジニアリングツール。

REAは、AIエージェントと連携し、ソースコードが公開されていないアプリや実行ファイルの内部構造・処理の流れを調査するツール。解析結果をもとに、AIエージェントが類似機能を実装する用途にも使える。

Claude CodeやCodexなどのAIエージェントとMCP経由で連携し、JavaScript・Electron製アプリ、Webサイト、ネイティブバイナリなどの内部構造や処理の流れを解析できる。

公式事例にはNotionのコピー処理の追跡、Chromeの恐竜ゲーム由来のブラウザ版の加速処理の調査と速度調整機能付きの再現、Windows電卓の「%」ボタンの計算処理の調査と再現がある。

REAはAIエージェントに解析手段を提供する仕組みで、ネイティブバイナリの詳細解析にはGhidra・Hopper・IDAのいずれかが必要。MITライセンスで公開。

※Claude CodeやCodexでREAを利用したユーザが、利用規約違反としてアカウント削除される事案が確認されています。利用には注意しましょう。

▼利用条件

AIツール【必須】MCP対応のAIエージェント（Claude Code・Codexなど）
実行環境【必須】Node.js・npm
