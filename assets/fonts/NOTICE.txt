Replacing the derived font with its original IPA Gothic font
Download IPAfont00303.zip from https://moji.or.jp/ipafont/ipa00303/ .
Extract ipag.ttf and replace the @font-face source for CookieTitle with that file,
or install IPA Gothic on the device and use font-family: "IPAGothic".
Remove the CookieTitle web-font reference when using the installed original.
The site includes the unchanged editable TTF; no additional font source files
were produced when preparing this site. CSS synthetic bold does not modify it.

日本語の原フォント置換手順：
https://moji.or.jp/ipafont/ipa00303/ からIPAfont00303.zipを取得し、ipag.ttfを展開する。
CookieTitleの@font-faceの参照先をipag.ttfへ変更するか、IPAゴシックを端末へ
インストールし、font-familyをIPAGothicに変更してCookieTitleの参照を外す。
